# Shape template: how-to

A how-to guide gets a reader who already knows the product through one task. It assumes the reader knows what they want, and it teaches nothing on the way.

When planning declares a docspec, it copies the layout below into the docspec's `## Where`, after the path, and the shape below into its `## Shape`. The owner adjusts both. The docspec never names this template.

## Layout

```
One file per task, named for the task as a reader would say it.
```

## Shape

```
Each guide holds these parts, in this order:

1. The task: one sentence on what the reader gets done.
2. Steps: numbered, one action per step, each with the command or code
   to type.
3. The result: what the reader has when the steps are done.
4. Common failures: each failure a reader is likely to meet on these
   steps, and how to fix it.
```
