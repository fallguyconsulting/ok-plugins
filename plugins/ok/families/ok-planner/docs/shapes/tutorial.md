# Shape template: tutorial

A tutorial teaches a new reader by having them do something real, one lesson at a time, in order. Each lesson ends with something working that the next lesson builds on.

When planning declares a docspec, it copies the layout below into the docspec's `## Where`, after the path, and the shape below into its `## Shape`. The owner adjusts both. The docspec never names this template.

## Layout

```
One file per lesson, its name starting with its number so the files
sort in the order a reader takes them.
```

## Shape

```
Each lesson holds these parts, in this order:

1. Goal: one sentence on what the reader has working at the end.
2. What you need: what the reader must have done or installed first,
   naming the earlier lesson where one provides it.
3. Steps: numbered, one action per step, each with the command or code
   to type.
4. What you should see: the output or result that shows the lesson
   worked.
```
