# An issue a person has not read counts as new analysis to that person

## Choice

An open issue filed since a person began working the intake, which
that person has not yet read, counts as new analysis to that person,
whoever filed it (see also: closed-issues-leave-new-analysis).

## Rationale

An issue a person has never read is new in the plain sense, and a
verified defect issue never asks for a ruling, so no other signal
marks a new one.

## Alternatives

- Filing stays silent, as a first routing does — an issue nobody has read, a verified defect issue above all, carries no signal.
- Filing writes one unread message on each issue — every issue carries a message that says nothing beyond its own fields.
