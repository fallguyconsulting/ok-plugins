# True-up brings a live sprint's retired boilerplate current

## Choice

In a sprint not yet archived, true-up brings the retired boilerplate
current, line for line, and leaves the rest of the sprint as written.

## Rationale

A live sprint is the one record an executor still acts on, and its
boilerplate is suite text the executor follows; a line naming a
retired path or contract item sends the executor to something that no
longer exists, and the current line changes no work the owner
approved.

## Alternatives

- Leave live sprints as written — a sprint planned under an earlier release runs retired steps.
- Ask the owner per sprint — a question every migrated project meets on its first true-up.
