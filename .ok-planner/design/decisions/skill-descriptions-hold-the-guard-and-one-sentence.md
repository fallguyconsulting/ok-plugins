# A skill's description holds its guard and one sentence

## Choice

Each suite skill's description holds its activation guard (see also:
slash-only-activation) and one short sentence naming what the verb
does, and nothing more.

## Rationale

The harness carries every skill's description into the skill listing of every session, and of every agent that holds the Skill tool, and each reads the listing again on every request. On one project the listing ran 29,734 characters for 52 skills, and the suite's three longest descriptions ran past 1,400 characters each. A skill that runs only on its slash command or from the caller its guard names is never chosen from its description, so the description needs only the guard and enough for a reader to tell what the command does. Every sentence past that costs every request and steers nothing.

## Alternatives

- Descriptions that summarize the skill's whole process — every session and agent rereads the summary on every request, and nothing chooses the skill from it.
- The guard alone, with nothing on what the verb does — the listing then tells no reader which command does what.
