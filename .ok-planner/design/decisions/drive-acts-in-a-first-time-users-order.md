# A driver acts in the order a first-time user would

## Choice

A driver acts in the order a first-time user would (see also:
drive-takes-every-named-variant).

## Rationale

Acting in a first-time user's order finds a failure that waits on a
fresh start, such as the first control a new user presses.

## Alternatives

- Any order the driver picks: a driver that starts from where its own
  earlier steps left the product skips the fresh start, and a failure
  that waits on it goes untried.
