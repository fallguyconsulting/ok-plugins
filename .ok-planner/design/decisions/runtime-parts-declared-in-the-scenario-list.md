# The scenario list declares the runtime parts

## Choice

The runtime parts and the classes that apply to each are part of the
scenario list (see also: scenario-list-decided-once).

## Rationale

Declaring the runtime parts in the same list gives the tests one
record of what they must cover.

## Alternatives

- A corpus kind for runtime parts, changed through sprint deltas: a
  second path that changes one list.
