# Report of code drift from lint rules and corpus citations

## Story

As a project owner, I want a report of where my codebase drifts from its declared lint rules and where its citations of corpus artifacts fail to resolve — an audit that changes nothing it examines — grouped so I can tell mechanical fixes from structural questions, so that remediation happens at my direction rather than being applied silently.
